Admin

Every control here is a fixed choice, and none can touch your files.

Nothing on this page can reach the file system or run a command: it can't name a file or a path, and its changes go only to the demo's state and to the policy database shown below.

There's no login. Every service listens on 127.0.0.1 and, when Tailscale is running, on this machine's tailnet address, so anyone on your tailnet can use this page, and the worst outcome is changed or reset demo data. Writes naming another Host or web origin are refused.

Policy

Policy store

The one real policy database. Flows run in scopes of their own, and never change it. It changes only when you act on it here or on the account page.

Kept in saved policy: guardians on file, delegations, app grants, rules, settings, the signing key, and token records, as SHA-256 hashes. Kept only in memory: sign-ins in progress, authorization codes, account sessions, used assertion IDs, the demo clock, and backend client keys.
